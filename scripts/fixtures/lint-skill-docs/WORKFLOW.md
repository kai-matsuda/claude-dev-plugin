# Sample workflow runbook

Fixture runbook the lint regression test copies; carries the content the lint requires and
no retired wording.

A workspace session is typed at the workspace root, and a feature is resumed from the workspace
root: resume from the workspace root. The inbox is the home's beads.

```
/grill-with-docs → /to-spec → /spec-to-stories → /spec-to-tickets → /implement-spec → /close-epic
```

**The argument.** The cut skills take the feature as their one argument.

| Stage | Session model |
|---|---|
| 1–3b | fable |
| 1 | fable |
| 3a | `/spec-to-stories <KEY>-<n>` |
| 3b | `/spec-to-tickets <KEY>-<n>` |
| 4a | opus |
| 5 | review |
| 8 | close |

Exploration notes live in `<repo>/.spec-notes/<epic-id>/`. Each story bead is run by
`/implement-story <story-id>`, with GLOSSARY.md as the vocabulary; merge its PR, then run `/close-story <story-id>`.
A human stop prints the PR to merge and the /close-story <story-id> to run.
In add mode, the cut extends a feature whose stories exist.
